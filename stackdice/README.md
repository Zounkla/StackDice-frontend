# Stack Roulette – Frontend Vue 3

```bash
npm install
npm run dev      # http://localhost:5173 (API proxifiée vers http://localhost:8080)
npm run build
```

Les valeurs des filtres/formulaires (catégories, compatibilités) sont dans `src/constants/enums.js` :
synchronisées avec les enums Java `Category` et `Compatibility`.
